# 📊 Sales Data Visualization

## 📌 Project Overview
This project was designed to reshape and provide clear visualizations for corporate sales data. Following instructions from the Managing Director, the goal of this exercise is to act as the junior data scientist "Mr. Bean" and organize the data into various clear dimensions. 

## 🗄️ Dataset
* **Source:** `assignment-data.xlsx` (specifically utilizing the `sales-data` sheet).

## 🛠️ Tasks & Visualizations
* **Part 1: Product & Supervisor Summary:** Generates a pivot table and a stacked bar chart to display product details (Monitor, Software, printer, search engine) produced by each company, organized by their respective supervisors, David Anderson and Peter Prince.
* **Part 2: Top Companies by Orders:** Groups the data to find and visualize the top 5 companies with the highest `total-quantity` ordered using a customized bar chart.
* **Part 3: Price vs. Quantity Scatterplots:** Creates side-by-side scatterplots showing `total-quantity` versus `Price` for three specific companies: Apple, HCL, and Infosys. 

## 💻 Technologies Used
* **Python**
* **Pandas:** Used for data manipulation, filtering, grouping, and creating pivot tables.
* **Matplotlib:** Used for rendering the stacked bar charts, standard bar graphs, and scatterplots.

## 📁 Repository Structure
* `sales-data-visualization-of-companies.ipynb`: The complete Python codebase containing the data reshaping, pivot table creation, and Matplotlib visualizations.
* `assignment-data.xlsx`: The dataset used for the analysis, specifically utilizing the `sales-data` sheet.
